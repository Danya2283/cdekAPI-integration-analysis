# Участники процесса и матрица ответственности

## Бизнес-участники

**Владелец магазина / Product Owner**
Формулирует бизнес-цели и приоритеты, принимает решения по скоупу, подписывает приёмку результата.

**Менеджер по работе с заказами**
Текущий владелец ручного процесса. Обрабатывает исключения которые автоматика не может решить. Контролирует статусы доставки в CRM.

**Клиент интернет-магазина**
Вводит данные при оформлении заказа, отслеживает статус доставки в личном кабинете.

---

## Технические участники

**Бизнес-аналитик**
Сбор и фиксация требований, формирование ТЗ, согласование между заказчиком и командой разработки, приёмочное тестирование.

**Backend-разработчик**
Реализация интеграции с API СДЭК, очереди задач и retry-логики, обработка webhook-уведомлений.

**QA-инженер**
Тестирование интеграции в тестовой среде СДЭК, проверка граничных случаев и обработки ошибок.

**Представитель СДЭК**
Предоставляет доступ к API и документацию, обеспечивает работу sandbox, консультирует по специфике API.

---

## Матрица ответственности RACI

| Активность | PO | Менеджер | БА | Backend | QA | СДЭК |
|---|---|---|---|---|---|---|
| Формирование требований | A | C | R | I | I | I |
| Написание ТЗ | I | C | R | C | I | I |
| Разработка интеграции | I | I | C | R | I | I |
| Тестирование | A | I | C | I | R | C |
| Приёмка результата | R | C | C | I | I | I |
| Поддержка после запуска | I | R | I | C | I | C |

R — выполняет, A — отвечает за результат, C — консультирует, I — информируется
