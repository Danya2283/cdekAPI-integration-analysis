# Матрица ошибок и сценарии обработки

## Классификация

- 🔴 Критические — заказ не создан, нужно вмешательство
- 🟡 Некритические — процесс идёт, восстанавливается автоматически

---

## 🔴 Критические ошибки

### ERR-01 — API СДЭК недоступно при создании отправления

| Параметр | Значение |
|---|---|
| Триггер | POST /orders вернул timeout или 5xx |
| Причина | Плановые работы СДЭК, сетевой сбой |
| Обработка | Retry: 1 мин → 5 мин → 15 мин → 1 час |
| После 4 попыток | Статус → requires_manual_processing, алерт менеджеру |
| Клиенту | «Ваш заказ принят, доставка будет оформлена в ближайшее время» |
| Менеджеру | Email + CRM-задача с номером заказа и контактом клиента |

### ERR-02 — Ошибка авторизации в API СДЭК

| Параметр | Значение |
|---|---|
| Триггер | API вернул 401 Unauthorized |
| Причина | Истёк токен, невалидный API-ключ |
| Обработка | Система пытается обновить токен; если не удалось — алерт devops |
| После сбоя | Новые запросы ставятся в очередь до восстановления авторизации |
| Клиенту | Аналогично ERR-01 — без технических деталей |

### ERR-03 — Невалидные данные заказа

| Параметр | Значение |
|---|---|
| Триггер | API вернул 400 Bad Request |
| Причина | Некорректный формат адреса, отсутствует обязательное поле |
| Обработка | Запрос не повторяется — это логическая ошибка |
| Статус заказа | → data_validation_error |
| Клиенту | «Не удалось оформить доставку. Проверьте адрес» + форма редактирования |
| Менеджеру | Алерт с телом ошибки от API СДЭК |

### ERR-04 — Дублирующее отправление

| Параметр | Значение |
|---|---|
| Триггер | Повторный запрос с тем же order_uuid |
| Причина | Retry после timeout, двойной клик |
| Обработка | API возвращает существующий cdek_order_uuid без создания нового |
| Клиенту | Штатное поведение — дубль незаметен |

## 🟡 Некритические ошибки

### ERR-05 — Webhook не доставлен или доставлен с задержкой

| Параметр | Значение |
|---|---|
| Триггер | Статус изменился, но webhook не пришёл в течение 6 часов |
| Причина | Сетевой сбой на стороне СДЭК |
| Обработка | Polling каждые 6 часов через GET /orders/{uuid} |
| Клиенту | Статус обновится с задержкой |

### ERR-06 — Невалидная подпись входящего webhook

| Параметр | Значение |
|---|---|
| Триггер | Подпись запроса не совпадает с ожидаемой |
| Причина | Попытка подделки запроса, ошибка конфигурации |
| Обработка | Запрос отклоняется с кодом 401 |
| Лог | Фиксируется IP-адрес, время, тело запроса |
| Алерт | При более 5 невалидных запросов за 10 минут — алерт в безопасность |

### ERR-07 — Превышен rate limit API СДЭК

| Параметр | Значение |
|---|---|
| Триггер | API вернул 429 Too Many Requests |
| Причина | Превышен лимит запросов в минуту |
| Обработка | Запрос откладывается на время из заголовка Retry-After |
| Клиенту | Не уведомляется — задержка незаметна |
