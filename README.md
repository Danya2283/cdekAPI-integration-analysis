# Анализ интеграции интернет-магазина с API СДЭК

## О проекте

Учебный кейс в формате реального проекта - тестовое задание на позицию 
стажёра-аналитика.

**Контекст:** интернет-магазин электроники TechDrop (~500 заказов/день) 
автоматизирует создание отправлений через API СДЭК. 
До интеграции менеджеры создавали накладные вручную — ~15 минут на заказ.

**Роль:** бизнес-аналитик — сбор требований, описание процесса, 
формирование ТЗ для команды разработки.

## Ключевые решения

**Idempotency Key** - каждый запрос к API СДЭК содержит уникальный 
идентификатор заказа для защиты от дублирования отправлений при retry.

**Очередь retry** - при недоступности API запрос не теряется, 
а повторяется до 4 раз с нарастающей задержкой (1 мин → 5 мин → 15 мин → 1 час).

**Webhook + Polling** - основной механизм получения статусов через webhook, 
резервный - polling каждые 6 часов при потере уведомлений.

**Двухуровневая классификация ошибок** - критические (требуют вмешательства) 
и некритические (восстанавливаются автоматически).
